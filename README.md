# Student-Task-Manager
Student Task Manager is a simple web application designed to help students organize, track, and manage their daily academic tasks, assignments, and study activities in one place
#### Student Task Manager Project – FSD Explanation

FSD (Full Stack Development)

### 1\. Project Introduction
The Student Task Manager is a web application that helps students manage their daily tasks, assignments, exams, and deadlines in one place.

### 2\. Objective
The main objective is to help students organize their work, complete tasks on time, and improve time management.

### 3\. Technologies Used
* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Database: MongoDB

### 4\. Main Features
* Add Task: Students can add new tasks.
* View Tasks: Students can see their task list.
* Edit Task: Students can update task details.
* Delete Task: Students can remove tasks.
* Mark as Completed: Students can mark finished tasks.
* Deadline: Students can set due dates for tasks.

### 5\. How It Works

Frontend-->HTML, CSS, React
Backend-->Node.js, Express.js
The student adds a task through the frontend. The backend processes the request, and the database stores the task details. The student can later view, edit, complete, or delete the task.

### 6\. Advantages
* Saves time.
* Organizes assignments.
* Helps meet deadlines.
* Improves productivity.
* Reduces the chance of forgetting tasks.

### 7\. Conclusion
The Student Task Manager is a useful FSD project that helps students manage academic activities efficiently. It demonstrates how frontend, backend, and database technologies work together to build a complete web application.
